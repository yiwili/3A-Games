# 深夜便利店：KONBINI NIGHT SHIFT

这是 3A-Games 的第五个同级项目：一款日系深夜便利店模拟游戏。

你将在凌晨两点半接管一家灯光过亮、货架永远补不完、微波炉疑似连接异世界的便利店。第一版目标不是成为商业巨作，而是先让你能走进店里，并对每一瓶饮料产生职业性的怀疑。

## 技术

- Godot 4
- GDScript
- Godot 原生几何体程序化搭景
- 预留 `.glb` / `.gltf` 模型替换空间
- 地面使用 ambientCG 的 `Tiles074` 1K PBR 贴图（CC0）

## 运行

用 Godot 4 导入本目录，运行 `main.tscn`。

操作：

- `WASD`：移动
- 鼠标：环顾
- `ESC`：释放鼠标

## 建模策略

第一阶段使用代码生成的细节模型快速验证玩法：货架、层板、饮料、零食、热食柜、收银台、玻璃门窗、霓虹招牌和灯光都在 `main.gd` 中生成。

第二阶段可以把重点物件替换成 Blender 制作的 `.glb`：收银机、微波炉、饭团、店员、自动门，以及那个明显不该出现在冷藏柜里的发光猫。
